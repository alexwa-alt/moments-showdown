# Seesaw Showdown

Y10 Physics pair game: moments and centre of gravity, using students' own faces.

The whole game is ONE file: `index.html` (page, styling and code together). Upload just that file.

## Put it on GitHub Pages (browser only, nothing to install)
1. github.com -> New repository (e.g. `seesaw-showdown`), Public.
2. Click "uploading an existing file", drag in `index.html`, then Commit changes.
3. Settings -> Pages -> Deploy from a branch -> main, / (root) -> Save.
4. After a minute: https://YOUR-USERNAME.github.io/seesaw-showdown/

The file must be named exactly `index.html` and sit at the top level of the repository.

## Moodle
Use a URL resource, or an iframe that includes `allow="camera"`:
<iframe src="https://YOUR-USERNAME.github.io/seesaw-showdown/" allow="camera" width="100%" height="900" style="border:0"></iframe>

## Privacy
Photos stay in the browser tab's memory only. Nothing is uploaded or saved.

## Editing
Search `index.html` for: `gen` (question numbers), `buildRounds` (round order), `:root` (colours), `WIN_LINES` (phrases).
